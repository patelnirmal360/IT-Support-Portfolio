## Why do organisations need identity management?

Have you ever used a computer in a library, school, or workplace where you were not allowed to change certain settings or access certain resources?

This is an example of how organisations can control what users are allowed to do on their computers and within their environment.

Let's imagine that I start a company called **Dummy Corporation**.

At the beginning, the company has only **10 employees and 4 computers**, so managing users and computers is relatively simple.

But after a few years, the company grows and hires another **100 employees**.

Now there are more than 100 users, many computers, applications, files, and other resources that need to be managed.

Managing every user and computer individually would become difficult and inefficient.

This is where **identity and directory services** become important.

They allow organisations to centrally manage users, groups, computers, authentication, and access to resources.

---
## What is Microsoft Entra ID?

Microsoft Entra ID is a **cloud-based Identity and Access Management (IAM) service**.

It helps organisations manage digital identities and control access to applications and resources.

For example, when an employee signs into Microsoft 365, Entra ID can authenticate the user's identity and help determine whether that user is allowed to access the service.

Entra ID can be used to manage:

- Users
- Groups
- Applications
- Devices
- Roles and permissions
- Authentication
- Access to cloud resources
